# Timeular for Homey

*Turn the die, set the scene.*

A [Homey](https://homey.app) app that turns the **Timeular Tracker** — the eight-faced time-tracking die — into a physical scene selector. Each face becomes a Flow trigger; what a face *does* is decided in your Flows, not in the app.

> [!NOTE]
> Community app, not affiliated with Timeular. Status: **v1.0.0**, submitted to the Homey App Store. The Timeular brand is now EARLY (part of TimeTac); the tracker is unchanged.

## What it gives you

| Flow card | Kind | Use |
|---|---|---|
| *The die turned to a face* | trigger, token `face` (1–8) | one Flow that dispatches on the number |
| *The die turned to face [N]* | trigger with argument | one Flow per face |
| *The die is / isn't on face [N]* | condition | guard other Flows |

The device also shows the current face and the battery level.

**Settle time.** Rolling the die crosses several faces in a second. A face only fires once the die has rested on it for the *settle time* (device setting, default 1500 ms).

## How it works

```
Tracker ──BLE──▶ Homey Pro (this app) ──▶ Flow trigger "face N"
```

The tracker exposes one byte — the face up (1–8, 0 on an edge) — on a GATT characteristic. No bonding is needed: a plain connection is enough. The protocol constants live in `lib/protocol.js`.

| What | UUID |
|---|---|
| Orientation service | `c7e70010-c847-11e6-8175-8c89a55d403c` |
| Orientation characteristic | `c7e70012-c847-11e6-8175-8c89a55d403c` |
| Battery | standard `0x180F` / `0x2A19` |

The tracker **sleeps when still** and stops advertising: move it during pairing, and after a long rest.

## Requirements

- Homey Pro (BLE apps run locally; not Homey Cloud).
- A Timeular Tracker. It accepts **one connection at a time** — close the Timeular desktop/mobile app if it holds the die.

## Development

```sh
npm install --global homey   # CLI, Node ≥ 24, Docker
homey login
homey app run                # run with live logs, removed on Ctrl+C
homey app install            # install durably in dev mode
homey app validate --level publish
```

Sources of truth are in `.homeycompose/` and `drivers/*/driver.*.compose.json`; `app.json` is generated by `homey app build`.

```
.homeycompose/       app manifest, custom capability
drivers/tracker/     pairing, device connection, flow cards
lib/protocol.js      Timeular BLE protocol
locales/             en, fr
README.txt           App Store description (plain text)
```

## Field notes

- Verified on Homey Pro: orientation updates arrive as BLE notifications (no polling needed).
- Battery under a permanent connection: 87 % → 86 % in 24 h (2026-11-21/22).
